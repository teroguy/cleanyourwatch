## 🚀 Быстрый старт

### Шаг 1: Подключите часы по Wi-Fi
1. Включите **Параметры разработчика** на часах (в меню *О часах* быстро нажмите 7 раз на *Номер сборки*).
2. Включите **Отладка по ADB** и **Беспроводная отладка** (Wireless debugging).
3. Подключите компьютер через ADB (подробная инструкция: **[docs/HOW_TO_CONNECT.md](docs/HOW_TO_CONNECT.md)**):
   ```bash
   adb connect <IP_ЧАСОВ>:<ПОРТ>
   ```

### Шаг 2: Запустите CleanYourWatch

Клонируйте репозиторий и запустите скрипт оптимизации:

```bash
git clone https://github.com/teroguy/cleanyourwatch.git
cd cleanyourwatch
./tools/clean.sh
```

Скрипт автоматически:
1. Определит модель и производителя часов.
2. Создаст полный резервный снимок в папку `backup/<модель>_<дата>/`.
3. Сверит пакеты со списком безопасности `tools/guards.txt` (защита от бутлупа).
4. Безопасно заморозит OEM-хлам и телеметрию через `pm disable-user`.
5. Применит системные твики (анимации 0.5x, отключение скрытого фонового поиска сетей).

## 🤖 Использование с ИИ-ассистентами

Вы можете запустить CleanYourWatch в диалоговом режиме через **Antigravity CLI**, **Claude Code** или **Cursor**:
1. Откройте папку репозитория в вашем ассистенте.
2. Вставьте текст из файла **[`PROMPT.md`](PROMPT.md)**.
3. Ассистент опросит вас о ваших сценариях (нужен ли умный дом, голосовой помощник, конкретные датчики) и настроит часы точно под вас.

## 🛡️ Как это работает

* **Безопасное отключение (`pm disable-user --user 0`)**: Никакие системные файлы не удаляются физически из памяти часов. Пакеты лишь "замораживаются". После обновления прошивки или сброса часы останутся полностью работоспособными.
* **Защитные списки (`tools/guards.txt`)**: В скрипт зашит жесткий список защиты критических компонентов Wear OS (безель/коронка, службы Bluetooth, базовый интерфейс часов и шина сенсоров).
* **Профили производителей**: Скрипт подбирает список очистки именно под ваш бренд (Bixby и Knox для Samsung, Mobvoi Appstore для TicWatch).

## 🔄 Восстановление

Чтобы вернуть все отключенные пакеты в исходное состояние:

```bash
./tools/restore.sh
```

Либо восстановитесь из конкретного бэкапа:
```bash
./backup/<папка_бэкапа>/restore.sh
```
